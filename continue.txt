Cube Clean — 다른 PC에서 이어서 작업하기
==========================================

1. 새 PC에서 할 일
------------------
git clone https://github.com/gitasin/claude.git
cd claude
git checkout gita1
cd cybercube
npm install
npx.cmd firebase login        (배포하려면 필요. gitasin0@gmail.com 계정)

그다음 VS Code로 claude 폴더를 열고 Claude Code를 실행.
이전 PC의 Claude Code는 종료해서 세션이 헷갈리지 않게.


2. 새 Claude 세션에서
---------------------
따로 붙여 넣을 것 없음.
claude 폴더의 CLAUDE.md를 Claude가 시작할 때 자동으로 읽음
(작업 규칙, 배포 방법, 지금 게임 상태, 출시 전에 할 일이 다 들어 있음).

처음에 이렇게만 말하면 됨:
  "CLAUDE.md 읽고 Cube Clean 이어서 하자"
